OAuth 2.0 / OpenID Connect

Rich Authorization Requests

Enable the domain's authorization detail types this client may request through the authorization_details parameter (RFC 9396). Requests carrying any other type are rejected.

Types are created and described at domain level, under OAuth 2.0 > RAR.

  • User consent — how long the user's approval of the type is remembered for this client. When empty, the type's own expiry applies, then the gateway default (oauth2.approval.expiry, one month unless configured).
