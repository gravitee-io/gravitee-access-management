Web protection

Configure HTTP security headers and CORS for your security domain.

Changes take effect without restarting the system.

By default, each setting follows the platform configuration. Turn off inherit to customize or disable a protection for this security domain only.

CSP directives

CSP directive values are saved exactly as you type them, so quoting matters:

  • Keywords and tokens need single quotes — 'self', 'none', 'unsafe-inline', 'strict-dynamic', as well as nonces or hashes.
  • URLs, hostnames, schemes and paths must be unquoted — https://cdn.example.com, *.example.com, data:, /csp-reports.
  • Separate multiple sources with spaces, for example 'self' https://cdn.example.com data:.
  • Use one directive per row and leave semicolons out — they are added for you. A few directives, such as upgrade-insecure-requests, take no value at all.
