SPIFFE

SPIFFE (Secure Production Identity Framework For Everyone) issues short-lived workload identities as JWT-SVIDs. When SPIFFE is enabled, applications in this domain can use the spiffe_jwt token-endpoint authentication method: clients present a JWT-SVID instead of a client secret, and AM verifies it against a configured trusted domain bundle.

The JWT-SVID validation policy on this page is SPIFFE-specific. Per-trusted-domain key sources and refresh intervals, and the domain-wide key retrieval limits that govern every trusted domain, live under Security → Trusted Domains.
