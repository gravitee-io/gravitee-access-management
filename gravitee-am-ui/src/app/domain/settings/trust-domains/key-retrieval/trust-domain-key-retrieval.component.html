Key retrieval

These limits apply to every trusted domain in this security domain, whichever usage it serves. They bound what AM will fetch when a trusted domain resolves its keys from a JWKS URL, and how long the resolved keys are kept.

Key sources and refresh intervals are set per trusted domain, on the trusted domain itself. Leaving both SSRF toggles off keeps AM from fetching keys over plain HTTP or from addresses on the internal network.
