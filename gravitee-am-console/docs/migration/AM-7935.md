## Endpoints

From `DomainService`, `DataPlaneService`, `UserPreferencesService` and `AnalyticsService`. `{env}` is
`/organizations/{org}/environments/{env}`.

- `GET {env}/domains?page&size`, `GET {env}/domains?q=*text*&page&size`: the list and the search.
- `GET {env}/domains?ids=..&ids=..`: the pinned-only filter. The page filters by name and pages in memory, as Angular.
- `GET {env}/domains/_hrid/{hrid}`: the domain scope. Angular reads the domain by id, and the console URL holds the hrid.
- `GET {env}/domains/{id}/members/permissions`: the domain permissions.
- `PATCH {env}/domains/{id}` with `{ enabled }`: the enable action of the disabled-domain banner.
- `POST {env}/domains` with `{ name, description, dataPlaneId }`: the create. The description goes only once typed.
- `GET {env}/data-planes`: the data planes of the create form.
- `GET /user/preferences`, `PUT /user/preferences` with the whole preferences object: the default and pinned domains.
- `GET {env}/domains/{id}/analytics?type&field&from&to&interval[&size]`: 13 calls per dashboard load, as `spikeNotes`.

The endpoints agree with `spikeNotes`. The pinned and default domain calls are newer than the spike.

## Shared part changed

`src/app/components/DomainSwitcher.tsx`, from AM-7933, gets a search, at the user's request. It is a Graphene `Popover`
with `Command`, and it filters the loaded domains by name. The Angular navbar picker also shows Current, Default and
Pinned sections, with pin and default toggles on each row, and it searches on the server. Those parts are not ported.

## Prototype additions left out

- The Path column of the list: not in AM.

## Angular behaviour added back

- The description under the domain name in the list. The prototype drops it.
- The disabled-domain banner with its enable action, for `domain_settings_update`. The prototype has no banner.
- The domain index redirect by permission. The prototype always opens the dashboard.
- Dashboard: every series of a histogram, a per-widget failure, registration as completed of total, top applications
  with a link for each application that is not deleted, and the Angular time ranges. See `spikeNotes`.

## Verification

2026-10-28, against the AM local stack (`local-stack.sh up --ui --quick`, MongoDB) with the Angular console on `:4200`
and the React console on `:4201`. Start the stack with `BUILDX_BAKE_ENTITLEMENTS_FS=0` if `buildx bake` asks for
`--allow=fs.read`.

- `yarn typecheck`, `yarn lint`, `yarn test` (138 tests) and `yarn build` pass.
- `npm run pw:next -- playwright/tests/console-next` in `gravitee-am-test`: 4 of 4 pass, with the setup.
  `domains-list.spec.ts` finds a domain by search, creates a domain with `{ name, dataPlaneId: 'default' }` and opens
  it. `domain-dashboard.spec.ts` sees the 13 analytics calls, then 13 more with the 90-day interval.
- Pin, set default, unset default and enable, on one domain in each console. The calls are the same:

    | Action        | Call, in both consoles                                                                |
    | ------------- | ------------------------------------------------------------------------------------- |
    | Pin           | `PUT /user/preferences` `{ pinnedDomainIds: [..., id] }`                              |
    | Set default   | `PUT /user/preferences` with `defaultDomainId: id`, `defaultEnvironmentId: 'DEFAULT'` |
    | Unset default | `PUT /user/preferences` with `defaultDomainId: null`, `defaultEnvironmentId: null`    |
    | Enable        | `PATCH .../domains/{id}` `{ enabled: true }`                                          |

- Pinned only reads `GET .../domains?ids=..&ids=..`. The search then filters the rows in memory with no call.
- After the enable, the banner closes. The domain index opens the dashboard for an admin.

Differences:

- The create page is at `new-domain`, not `domains/new`. See Pages.
- The page size is 25. Angular shows 10.
- The no-results state has no "Clear filters" button: `SearchField` keeps its own text, so the page cannot clear it.
- The pin and default actions show a toast. Angular shows none. The prototype adds the toasts.
